Corso DotNet + Angular

Il Progetto

Questa applicazione è stata realizzata come progetto dimostrativo nell'ambito del corso .NET + Angular. L'obiettivo è mostrare l'integrazione tra un backend in C# e un frontend in Angular.

Tecnologie utilizzate

  • Angular
  • ASP.NET Core Web API
  • TypeScript
  • C#
  • Entity Framework Core
  • sqlServer
  • Bootstrap
